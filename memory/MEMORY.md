# Memory index — Brewlog

Two tiers. **Always read** at session open, right after `AGENTS.md`: this
file and `_continuity.md`. **On demand**: every other file in this folder.
Read one when its line below matches the task in front of you, or when the
designer types `/vault-load <topic>`. Do not read them all at open; the
point of the split is that the always-read tier stays short.

- [Design system history](design-system-history.md) — what each version of
  the system changed and why, 1.0 to 1.2
- [Brewlog data model](brewlog-data-model.md) — what an entry is made of,
  the seed entries, what survives a reload
- [Exercise notes](exercise-notes.md) — what happened in each BRW ticket:
  the material for show and tell and the demo

`_continuity.md` — where the work is: open questions, work in flight, how
to resume. Overwritten by `/vault-save` at every close.
