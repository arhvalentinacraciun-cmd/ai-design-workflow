# Exercises

One ticket per session, four sessions. BRW-104 runs at home between S3
and S4 and is discussed in S4; BRW-105 is the demo brief for S4's second
half. Each is written the way a real ticket should be —
story, acceptance criteria, constraints — because that format is itself the
lesson: **the acceptance criteria define "done," not your memory of what you
wanted.**

## How to run one

1. Open the ticket. Read it fully before opening a session.
2. Kick off: *"Today we're doing BRW-1XX. The goal is [the story's goal]."*
   From Session 2 on, typing `/session-2`, `/session-3` or `/session-4`
   in Claude Code does steps 1 and 2 for you and shows the evening's
   hands-on agenda, so the whole room starts in the same state.
3. Work with Claude until every acceptance criterion is checked.
4. Say **"Session done."** and let the close protocol run: it writes the
   session's memory (`/vault-save`) and moves Track phase forward.
5. Commit.

Each ticket has a **stretch** section for experienced mentees — same theme,
harder cut. Do the base first; the stretch is optional, not a status symbol.
