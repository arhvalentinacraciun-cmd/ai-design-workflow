# BRW-105 · Demo day

| | |
|---|---|
| **Type** | Show your work |
| **Session** | S4 — Judgment and demo day, second half |
| **Goal** | Present what you built and how the system shaped it |

## Format

Three minutes, three beats, hard timer:

1. **The thing.** Show Brewlog running with your BRW-101 and BRW-103 work,
   and the skill you wrote for yourself in Session 2's twin (or your own
   project, if you transplanted the pattern; even better).
2. **The system.** Show one moment where the workflow did its job: the
   hook catching a literal, the memory defending a decision, the spec
   catching an ambiguity before code.
3. **The transplant.** One sentence: which piece of this repo goes into
   your real work first, starting Monday.

## Acceptance criteria

- [ ] The demo runs from your machine, live. No slides.
- [ ] A 60-second screen recording of the demo is ready as a fallback. If
      there are more demos than the session has time for, some run as
      recordings.
- [ ] `AGENTS.md` is up to date: Current State reflects everything shown.
- [ ] Your rubric proposal from BRW-104 is ready to share.

## After the program

This repo is yours. Rewrite `AGENTS.md` for a real project, swap the design
system for your own, keep the hook, keep the protocol. The training wheels
were the product.

## Twin (at home, optional)

None. Demo day is the last session; what you keep is the section above.
