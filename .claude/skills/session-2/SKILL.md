# Session 2 · Memory and skills

This file is tonight's first lesson. Last week everyone opened the session
by hand: read `CLAUDE.md`, check git, three sentences, wait for a ticket.
That is a process you repeat every session, so it became a skill. Typing
`/session-2` runs it. Everything you repeat often enough can be written
down the same way.

## 1. Open

Run the session-protocol open: read `CLAUDE.md` completely, run
`git status`, summarise the project state in three sentences.

If there is uncommitted work from BRW-101, say so and offer to commit it
before anything else. Last week's work should be safe before tonight's
starts.

If Track phase in `CLAUDE.md` still lists Session 1 as Next, last week's
close did not record it: move Session 1 to Done and set Next to
Session 2 · Memory and skills · Thu 12 Nov 2026 now, so the file is
right before tonight's work begins.

## 2. Load the ticket

Read `exercises/BRW-102-teach-it-memory.md` in full. Tonight the skill
supplies the kick-off line so the room starts together; the rest of the
protocol is unchanged. Say:

*"Today we're doing BRW-102. The goal is to experience project memory as
a constraint the AI actually respects."*

## 3. Tonight's hands-on, in order

| Block | About | What happens |
|---|---|---|
| BRW-102, part 1 | 15 min | Add a decision to `CLAUDE.md`, say "Session done.", start a fresh session and look for it in the three sentences |
| BRW-102, part 2 | 10 min | Ask for the thing the decision forbids. The refusal is the point |
| Build a skill together | 20 min | `/new-ticket`: one sentence in, a ticket with story and acceptance criteria out. Built live, then yours |

Show this table, then wait. Do not start part 1 until the mentee says so.
Part 1 ends the session on purpose; part 2 happens in the fresh one.

## 4. Close

On "Session done." run the session-protocol close. Then name this week's
twin, so it is in the chat before anyone leaves:

> Build a skill of your own for a process you repeat a lot. Bring it to
> Session 3 for show and tell. Optional: ask the agent to keep a roadmap
> file for your project.

Write it into Track phase in `CLAUDE.md`: Done gains Session 2, Next
becomes Session 3 · Design system, spec-first · Thu 19 Nov 2026, the twin
is the text above, Twin progress is "not started". Any session opened at
home this week will then start from there.
